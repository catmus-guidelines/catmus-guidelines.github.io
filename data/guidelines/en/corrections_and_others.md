For in-line corrections, we recommend using the combination of "⟦" [U+27E6] and "⟧" [U+27E7] to encapsulate a legible word marked as crossed out. When the word is not decipherable (because of a stain, an incomplete tracing or any other reason), "⟦" and "⟧" can be used without any letter in between ("⟦⟧"). <!-- AC: I almost want to say that this is also this symbol that should be used to mark transcription uncertainty during the transcription -->

For corrections relying on an interlinear addition, we first recommend that the interlinear addition be considered a separate text line, type accordingly using the SegmOnto vocabulary. In cases where a symbol is used in the source to mark where the interlinear addition should be inserted, we recommend to always use the same unicode character : "‸" [U+2038].
